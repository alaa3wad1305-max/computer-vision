# CNN vs EfficientNet Image Classification

## Project Overview
This project compares a CNN model trained from scratch with a pretrained EfficientNetB0 model using the CIFAR-10 dataset.

## Dataset
CIFAR-10 contains 60,000 images belonging to 10 different classes.
- 45,000 Training images
- 5,000 Validation images
- 10,000 Testing images

## Models
1. CNN from Scratch
2. EfficientNetB0 (Transfer Learning)

## Evaluation Metrics
- Accuracy
- Loss
- Training Time
- Confusion Matrix

## Results
Results are calculated after training and testing both models.

## Conclusion
The two models are compared based on their classification accuracy, loss, and training time to evaluate the advantages of transfer learning over training from scratch.
